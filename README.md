## Software Engineer Building Systems from Application to Cloud

I build **backend systems, cloud infrastructure, and cross-platform applications**.

My primary focus is **backend engineering and Google Cloud**, with a strong interest in distributed systems, reliability, and modern cloud architecture. I also build applications with **Flutter**, giving me the ability to work across the stack from user-facing products to the infrastructure behind them.

My background in Cloud and DevOps shapes how I approach software engineering: I care not only about writing code that works, but also about how that code is **deployed, observed, scaled, secured, and operated in production**.

I'm particularly interested in **Google Cloud, containers, serverless platforms, platform engineering, and modern and enterprise infrastructure**.

Beyond building software, I enjoy sharing what I learn through **technical writing, projects, and technical talks**.
